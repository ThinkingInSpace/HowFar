Privacy & credits

Updated October 1, 2026.

Your game stays in your browser

GeoRange has no accounts, ads, analytics, cookies, location requests, or persistent game storage. Your guesses and scores are calculated in this page and are not submitted to a server. Reloading the page resets your game. Game data, code, and globe imagery load from this website’s own host.

“Copy my score” writes your result to your clipboard only when you press it. Nothing is posted automatically. If copying is unavailable, the game provides a text box for manual copying.

The public site is hosted by GitHub Pages. GitHub logs visitors’ IP addresses for security purposes. See GitHub Pages data collection and the GitHub Privacy Statement. External links on this page open other sites with their own privacy practices.

Data & imagery

Made with Natural Earth. The 243 city names and coordinates match the Natural Earth 5.1.2 populated places dataset. Natural Earth data is public domain.

Earth imagery: NASA Blue Marble, distributed with the Three-globe 2.45.2 example. See NASA’s imagery usage guidelines. NASA does not endorse this game.

Software credits

The globe uses Globe.gl 2.46.2 and its bundled dependencies, including Three.js. See the Globe.gl MIT license and third-party license notices.

About the distances

This is a casual geography game. Distances approximate the shortest surface route on a spherical Earth between city coordinates; they are not flight, driving, or navigation instructions. Place names reflect the source dataset and do not express a position on sovereignty or borders. Scores are calculated locally and are not independently verified.

Report problems through the project’s issue tracker. Reports are public; do not include private information.
